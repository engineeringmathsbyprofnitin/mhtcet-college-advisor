# Stage 12c-3 - website colleges matched to NAAC records

`ingestion/naac_match.py`: for each of the 403 website colleges it looks for the college's record in `data/normalized/naac/naac_institutions.csv` (2,324 Maharashtra NAAC records). Strict rules (never guess): automatic link only when the name score is high, the best record clearly leads the second best (also on the plain name score), the place does not contradict, and no field word of another kind of college is involved (pharmacy / education / arts / MBA / hospital... are penalised when the website college is an engineering college). Everything else waits for the owner in `data/manual/naac_confirmations.csv` (college_code, aishe_id, decision yes/no). Two colleges claiming the same NAAC record are both left to the owner. Output: `data/normalized/naac_link/naac_college_match.csv` (+ report). "No record" means the college is not on the NAAC list we have, NOT "not accredited".
Old and new place names are treated as the same word (Aurangabad = Chhatrapati Sambhajinagar, Osmanabad = Dharashiv, Ahmednagar = Ahilyanagar); Mumbai, Mumbai City and Mumbai Suburban are one place for addresses.
Result with the owner's answers (125 pairs) plus 3 Mumbai colleges decided by the assistant: 233 colleges linked (A++ 12, A+ 43, A 59, B++ 48, B+ 36, B 34, C 1), 170 with no NAAC record, 0 doubtful.
Corrections made while finishing (assistant's own judgement, reported to the owner): three suggested links that duplicated an exact-name match were set to "no" (05239 Jamia Inst. of Technology, 05545 SVKM Dhule, 06138 Genba Moze Wagholi); 03203 Atharva and 03208 Don Bosco linked, 03209 K J Somaiya Institute of Technology has no NAAC record.
