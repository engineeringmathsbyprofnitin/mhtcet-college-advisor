# Stage 10c-3d - fixes after the first phone test (owner feedback)

1. **All 20 results shown at once (should be 5 + "Show more")** - cause: on phones the table body is made a block by `table.results tbody`, which was more specific than the rule `tbody[hidden]{display:none}`, so the hidden rows 6-20 were displayed. Fixed in styles.css (`table.results tbody[hidden]{display:none}`) and a test guards it. This bug was already in the earlier live page; it only shows on narrow screens.
2. **Candidate types** - the list now shows all three again; "All India candidate" and "Other Than Maharashtra (OMS) candidate" are shown greyed with "(coming soon)" because the data and rules for them are not built yet (their lists exist but are mostly JEE/NEET based; planned later).
3. **District always available** (owner decision, replaces the earlier greyed-out choice) - the district selector works normally ("Any district" is ticked by default; untick to choose districts). The official cutoff lists do not print districts, so no college has a district yet: the engine then says "District data is not available yet, so your district choice could not be applied and all districts were searched" instead of hiding every college. When district data is loaded the same choices will filter automatically.
4. **Vacancy warning** ("Vacancy data unavailable: no Round IV or Round III vacancy-position data found for 2026-27") is correct for now: vacancy lists are built in Stage 11. The text says Round IV or Round III (the rule); it never uses Round II.
